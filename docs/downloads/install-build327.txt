安装：
1. 先退出正在运行的旧版硬核。
2. 双击 PKG，按“继续 → 安装”操作；无需手动复制或拖动。
3. 如系统要求授权，使用这台 Mac 的登录密码或触控 ID；不是苹果公证密码。
4. 完成后，从“应用程序”打开“硬核 3.26”。应用图标为蓝紫色声波。
5. 语音识别模型未下载时，点击 App 中“下载并启用”。模型约 1.5GB，需要联网和磁盘空间。系统翻译资源也可能在首次使用时下载。
