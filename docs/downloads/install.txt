硬核 3.26 免开发者签名测试版

适用：Apple 芯片 Mac（M1/M2/M3/M4 等），macOS 26.4 或更高版本。
本安装包没有 Apple Developer 身份签名，也没有苹果公证。
为满足 Apple 芯片运行要求，程序保留本地临时签名；这不需要开发者账号。

安装：
1. 解压 ZIP，把“硬核免签测试版.app”拖入 Applications（应用程序）。
2. 在应用程序中打开它。
3. 如果系统提示无法验证开发者，关闭提示，打开“系统设置 → 隐私与安全”。
4. 找到刚才被阻止的硬核应用，点击“仍要打开”，按系统要求验证并确认。
   系统提示和按钮因 macOS 版本而异；受管理的电脑可能禁止运行。
无需关闭系统安全保护，也无需粘贴终端命令。

首次语音识别需要联网下载约 1.5 GB 的识别模型，中文翻译可能需要下载系统语言资源。
字幕识别、翻译和成片需人工复核；请保留原视频。
此包不适用于 Intel Mac，Intel 版本尚未完成运行验证。
