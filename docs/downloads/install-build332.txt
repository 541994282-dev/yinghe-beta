系统与设备

- 构建最低要求 macOS 15.7。安装器、App 元信息及主程序部署目标均为 15.7。

- 首次使用需联网下载约 1.5 GB 识别模型；系统翻译资源可能另需下载。

安装
1. 退出正在运行的旧版硬核。
2. 双击 PKG，按“继续”“安装”等系统提示完成安装。
3. 从“应用程序”打开“硬核 3.26”。安装器可能要求本机登录密码或触控 ID。
4. 在 App 左侧“设置”中下载识别模型，再导入视频，点击“开始处理”。

本版界面
- 深色三栏工作台，视频预览与字幕校对并排显示。
- 左侧“设置”为二级展开，不再使用遮挡视频的大型设置弹窗。
- 水印文字、位置、明显度及模型下载保留原有保存逻辑。
